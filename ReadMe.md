# easyClock

## A User-Friendly Desktop Application for Circadian Rhythm Analysis and Visualization

easyClock is a graphical desktop application designed for researchers to analyze, visualize, and export circadian rhythm data without programming requirements.

Developed for *Drosophila melanogaster* behavioral studies, easyClock integrates multiple circadian rhythm analysis approaches, including parametric, non-parametric, harmonic, and time-frequency methods, into a single user-friendly interface.

---

## Overview

easyClock provides an integrated workflow for:

1. Importing behavioral time-series data
2. Assigning biological groups
3. Performing circadian rhythm analysis
4. Visualizing fitted models and rhythmic patterns
5. Exporting publication-ready figures and statistical results

---



## Flexible Data Import and Group Management (data length >= 48 hr)

easyClock supports CSV-based behavioral datasets.

Features:

- Load up to three datasets simultaneously
- Automatically handle:
  - duplicate column names
  - unnamed columns
  - multiple biological replicates
- Assign individual samples into experimental groups
- Automatically calculate:

  - Mean behavioral profile
  - Standard error of the mean (SEM)


## Circadian Rhythm Analysis

1. Cosinor Analysis
2. Cosine-Kendall Analysis
3. Python-JTK Analysis
4. AR-JTK: Autocorrelation-Aware JTK Analysis
5. Harmonic Cosinor Analysis
6. Continuous Wavelet Transform (CWT)
7. Individual Rhythm Analysis
8. Linear Mixed-Effects Model


## Visualization

1. Actograms
2. Various rhythm Fitting Visualization
